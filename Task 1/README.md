# 🚀 TechNova Solutions

A modern, responsive multi-page business website built using HTML5 and CSS3 as part of my Full Stack Web Development Internship.

## 📌 Overview

TechNova Solutions is a fictional IT company website designed to showcase professional web design, responsive layouts, and clean user interfaces.

## ✨ Features

- Responsive Design
- Multi-page Website
- Modern UI
- Services Showcase
- Portfolio Section
- Blog Section
- Contact Page
- Cross-browser Compatible

## 🛠 Technologies Used

- HTML5
- CSS3
